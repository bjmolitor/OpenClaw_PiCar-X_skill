# OpenClaw_PiCar-X_skill
A skill for OpenClaw to use the sunfounder PiCar-X as a robot body

## Usage
The core interface is `aiagentctrl.py`. It provides a JSON-outputting CLI for controlling the robot.

See [aiagentctrl_aiguide.md](aiagentctrl_aiguide.md) for full documentation.
